# Alumni Connect

A full-stack MERN application designed to bridge the gap between students and alumni by providing networking, job opportunities, event management, donations, and real-time communication.

## Features

### Student/User

* Browse Alumni Directory
* Search Alumni Profiles
* Real-time Messaging
* View & RSVP Events
* Browse Jobs and Internships

### Alumni

* Alumni Registration
* Post Jobs & Internships
* Real-time Communication with Students
* Donations Portal
* Profile Management

### Admin

* Manage Users & Alumni
* Create and Manage Events
* Track Event Participation
* View Platform Analytics

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* React Router

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* JWT Authentication
* Role-Based Authorization

### Additional Services

* Socket.IO
* Cloudinary
* Stripe
